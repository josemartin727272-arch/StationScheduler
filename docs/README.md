# אשר סידור מוניות 🚕

אפליקציה לבניית סידור עבודה שבועי לתחנת מוניות. רצה כולה על המכשיר (אייפד / טאבלט / מחשב),
עובדת גם בלי אינטרנט, וכל הנתונים — הגדרות וארכיון סידורים — נשמרים בדפדפן של המכשיר בלבד.

**כתובת:** https://josemartin727272-arch.github.io/StationScheduler/

המדריך המלא נמצא בתוך האפליקציה: 📖 מדריך (עברית / English / Español).

## התקנה

- **אייפד / אייפון:** לפתוח את הכתובת ב-Safari ← כפתור השיתוף ← „הוסף למסך הבית”, ולפתוח תמיד מהאייקון.
- **אנדרואיד / מחשב:** לפתוח ב-Chrome ← ⋮ ← „התקנת אפליקציה” / „הוספה למסך הבית”.
- עדכון גרסה: לפתוח את האפליקציה פעם אחת עם אינטרנט — העדכון נטען לבד, והנתונים נשמרים.

## מה יש בה

| מסך | עיקר |
|---|---|
| 📋 סידור | צור שבוע · ⚡ שיבוץ אוטומטי · ↶ בטל שיבוץ · 💬 למה? · ⚖️ איזון השבוע · 💾 שמור · 📤 Excel · 🖨️ הדפסה ו-📄 PDF · 📲 שליחה לעובדים |
| ⚙️ הגדרות | קבוצות עובדים ושפת ההודעות · ✏️ שינוי שם עובד · מקומות עבודה וסדר שיבוץ · ימי ושעות עבודה · משימות מחזוריות · שורות ואפשרויות · 🧭 צירים, אחוזי צירים ועדיפות מונית מיוחדת · יעדים שבועיים · 📌 שיבוצים קבועים · 🏖 לוח חופשות · לוג שינויים |
| 📁 ארכיון | כל השבועות השמורים, לפי חודש · גיבוי ושחזור לקובץ |
| 📊 סטטיסטיקה | שבוע / חודש / שנה — חלוקה בין עובדים, ניצול חופשה, התפלגות ערכים |

**איזון:** עובדים מאוזנים בתוך השבוע (תיקו מוכרע לפי השבועות האחרונים); שאר הערכים — לפי 90 הימים האחרונים.

## הקבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | האפליקציה כולה (HTML + CSS + JS) |
| `service-worker.js` | עבודה בלי אינטרנט ועדכון גרסאות (`CACHE` עולה בכל גרסה) |
| `manifest.json` | שם, אייקון, מסך מלא |
| `vendor/` | html2canvas + jsPDF ליצירת PDF |
| `icon-192.png`, `icon-512.png` | אייקון |

בדיקות: `tests/pwa.test.js` בשורש הפרויקט (לא חלק מהאתר).

> ⚠️ הנתונים חיים רק בדפדפן של המכשיר. מחיקת נתוני האתר מוחקת גם את הארכיון — מומלץ 📁 ארכיון ← 📤 גיבוי הכול מדי פעם.
