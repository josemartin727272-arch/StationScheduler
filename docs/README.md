# סידור עבודה שבועי 🚕 — PWA

אפליקציית סידור עבודה לחברת מוניות. רצה **כולה מקומית** על הטאבלט — כל הנתונים
(הגדרות + ארכיון סידורים) נשמרים בזיכרון הדפדפן (localStorage) ולא עוזבים את המכשיר.

## הקבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | האפליקציה המלאה (HTML+CSS+JS בקובץ אחד) |
| `manifest.json` | הגדרות PWA — שם, אייקון, מסך מלא |
| `service-worker.js` | עבודה ללא אינטרנט (offline) |
| `icon-192.png`, `icon-512.png` | אייקון המונית |

## התקנה על טאבלט אנדרואיד — שתי דרכים

### דרך א' (מומלץ): התקנה מלאה כאפליקציה ("הוסף למסך הבית")

Chrome מאפשר התקנת PWA עם service worker **רק מכתובת ‎https://‎**.
לכן צריך להעלות את התיקייה הזו פעם אחת לאחסון סטטי חינמי — הכי פשוט GitHub Pages:

1. העלה את חמשת הקבצים לריפו GitHub (למשל תיקיית `docs/` בריפו קיים).
2. ב-Settings ‏→ Pages בחר את הענף והתיקייה — תקבל כתובת `https://<user>.github.io/...`.
3. פתח את הכתובת ב-Chrome על הטאבלט **פעם אחת** (עם אינטרנט).
4. תפריט ⋮ ‏→ **"הוספה למסך הבית"** ("Add to Home Screen") → אשר.
5. מעכשיו יש אייקון מונית 🚕 במסך הבית, האפליקציה נפתחת במסך מלא
   **ועובדת 100% בלי אינטרנט** — ה-service worker שמר עותק מלא במכשיר.

> העדכון היחיד שדורש אינטרנט הוא אם תרצה בעתיד גרסה חדשה של האפליקציה עצמה.

### דרך ב' (בלי אינטרנט בכלל): פתיחה כקובץ מקומי

1. העתק את התיקייה לטאבלט (כבל USB / כרטיס SD).
2. פתח את `index.html` ב-Chrome (דרך אפליקציית Files ‏→ פתח באמצעות Chrome).
3. האפליקציה עובדת במלואה — סידור, הגדרות, ארכיון, סטטיסטיקה, ייצוא והדפסה.

מגבלה טכנית של Chrome: מקובץ מקומי (`file://`) **אין** כפתור "הוספה למסך הבית"
ואין service worker — אבל הם גם לא נחוצים שם, כי הקובץ כבר יושב על המכשיר.
אפשר ליצור קיצור דרך רגיל לקובץ דרך תפריט Chrome.

> ⚠️ בשתי הדרכים הנתונים נשמרים ב-localStorage של Chrome. אל תמחק את נתוני
> האתר של Chrome (Clear browsing data ‏→ Site data) — זה מוחק את הארכיון.
> מומלץ מדי פעם לייצא שבועות חשובים ל-CSV כגיבוי.

## שימוש יומיומי

1. **📋 סידור** — בחר תאריך (נצמד אוטומטית ליום שני), לחץ "צור סידור",
   מלא חופשות/משימות ידניות, ואז **⚡ שיבוץ אוטומטי** ממלא את השאר לפי
   שוויון והיסטוריה מהארכיון. בסוף — **💾 שמור** לארכיון.
2. **⚙️ הגדרות** — עובדים, תקציבי חופשה, שמות שורות ב-3 שפות, אפשרויות כל
   רשימה, סדר שורות בגרירה (⠿), יעדים שבועיים, ושורות מותאמות אישית.
3. **📁 ארכיון** — כל השבועות השמורים: טעינה, מחיקה, ייצוא CSV.
4. **📊 סטטיסטיקה** — שבוע נוכחי / חודשי / שנתי: חלוקת עובדים, ניצול
   תקציב חופשה, והתפלגות ערכים של כל שדה.
